# Дата регистрации в Telewhite

## Источники и поведение

- Строка профиля остаётся под Telewhite ID и включается существующим показом ID пользователей.
- Если Telegram уже передал `CachedUserData.peerStatusSettings.registrationDate` (`MM.yyyy`), показываются только месяц и год. Эти данные имеют приоритет перед ответом бота.
- Если месяца нет, строка предлагает запрос через AyuGram. Открытие профиля ничего стороннему сервису не отправляет.
- Каждый новый запрос/обновление требует подтверждения: бот `@ayugrambot` получает проверяемый ID и может видеть инициатора inline-запроса. Переписка, телефон и геопозиция в запрос не включаются; отправки сообщения или `/start` нет.
- Провайдер проверяется и по имени, и по ID `6247153446`. Автоматического переключения на другие сервисы нет.
- `EXACT` и `INTERPOLATED` показываются с `≈`, как в AyuGram; это не подтверждённый Telegram день. `LT` — раньше, `ET` — позже. Невалидные ответы/даты, неизвестные флаги и будущие даты отвергаются.
- Таймаут — 15 секунд. Нет ответа — «Нет данных», с возможностью повторить. Уход/перестроение строки отменяет незавершённый запрос.
- Кэш разобранных ответов ограничен, разделён по аккаунту и профилю: успешные ответы до часа, отсутствие данных 30 секунд. Стандартный inline-кэш TelegramEngine может отдельно сохранять исходный ответ согласно `cacheTimeout` бота.
- Оценки по локальной таблице и ограничение ID в 8 миллиардов удалены. Дата не вычисляется из ID; деление на ноль в прежней интерполяции исчезло вместе с ней.

## Источник протокола

Изучена реализация AyuGram Desktop, `Telegram/SourceFiles/ayu/utils/telegram_helpers.cpp`, ревизия `db3b9891cb0b04ebb7d8c0e71ada3bcc669b910a`:
https://github.com/AyuGram/AyuGramDesktop/blob/db3b9891cb0b04ebb7d8c0e71ada3bcc669b910a/Telegram/SourceFiles/ayu/utils/telegram_helpers.cpp

Реализация на Swift написана независимо. Копии чужой базы ID/дат нет. Донатный `exteraAuthBot` не используется. Совпадение с конкретной версией AyuGram или точность сторонней базы не гарантируются.

## Проверки

На macOS из корня репозитория:

```sh
SOURCES=submodules/TelegramUI/Components/PeerInfo/PeerInfoScreen/Sources
xcrun swiftc -warnings-as-errors -parse-as-library \
  "$SOURCES/TelewhiteRegistrationDate.swift" Tests/TelewhiteRegistrationDateTests.swift \
  -o /tmp/telewhite-registration-tests
/tmp/telewhite-registration-tests
xcrun swiftc -frontend -parse "$SOURCES/TelewhiteRegistrationDateItem.swift" "$SOURCES/PeerInfoProfileItems.swift"
```

Это тесты реального Foundation-парсера и синтаксическая проверка UI, НЕ полная сборка iOS. Полная проверка типов TelegramUI и поведения на устройстве требует обычной сборки IPA.

Перед выпуском проверить на устройстве: профиль с месяцем Telegram; профиль без месяца (отмена подтверждения и успешный запрос); таймаут/нет сети; обновление результата; переход между аккаунтами; переключение языка; ID больше 8 миллиардов. Для случая «2024 против 2022» проверить ответ сервиса для того же ID — сами по себе два года не доказывают дату регистрации.
