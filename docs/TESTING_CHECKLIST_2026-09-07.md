### 🔴 CRITICAL #1: Registration Date — Division by zero

**Что тестируем:** Дата регистрации больше не показывает 2001-01-01 для "красивых" ID

**Как проверить:**
1. Открыть профиль пользователя с ID = **51**
2. Проверить что дата регистрации ≈ 1 ноября 2013 г. (НЕ 2001)
3. Повторить для ID:
   - **777000** (Telegram Service Notifications) — ≈ 25 сентября 2013 г.
   - **1000000** — ≈ 27 октября 2013 г.
   - **2000000** — ≈ 23 ноября 2013 г.
   - **3000000** — ≈ 11 декабря 2013 г.

**Ожидаемый результат:** Все даты корректные, НЕТ "2001-01-01"

**Если провалено:** Division by zero не исправлен

### 🔴 HIGH #2: Ghost Mode race condition

**Что тестируем:** Онлайн-статус не мелькает при включении Ghost Mode во время активности

**Как проверить:**
1. **Ghost Mode ВЫКЛЮЧЕН**
2. Открыть чат с кем-нибудь (онлайн появится)
3. Начать печатать сообщение
4. **Включить Ghost Mode** (Telewhite Mods → Невидимка → ON)
5. **НЕ закрывать чат**, продолжить печатать и отправить
6. Попросить собеседника посмотреть — был ли ты онлайн после включения

**Ожидаемый результат:** Онлайн НЕ показывался после включения Ghost Mode

**Если провалено:** Race condition не исправлен, онлайн мелькнул

**Дополнительная проверка:**
- Включить Ghost Mode
- Отправить несколько сообщений подряд
- Проверить что онлайн не появляется вообще

---

### 🟡 MEDIUM #3: Stories + per-chat ghost

**Что тестируем:** Per-chat ghost теперь работает для Stories

**Как проверить:**
1. Выбрать контакт у которого есть активная Story
2. **Включить per-chat ghost** для этого контакта (3 точки → Невидимка для этого чата)
3. Посмотреть его Story
4. Попросить контакт проверить — видел ли он что ты смотрел Story

**Ожидаемый результат:** Контакт НЕ видит что ты смотрел Story

**Если провалено:** Per-chat ghost для Stories не работает

---

### 🟡 MEDIUM #4-7: Memory Leaks (retain cycles)

**Что тестируем:** Нет утечек памяти в настройках модов

**Как проверить:**
1. Открыть Telewhite Mods
2. Включить/выключить несколько настроек:
   - Ghost Mode
   - Hide Ads
   - Auto Cache Cleanup (изменить лимит)
   - Translation language
3. Открыть несколько вложенных экранов (Privacy → Translation → Appearance)
4. Вернуться назад на главный экран
5. Повторить 5-10 раз

**Ожидаемый результат:** 
- Приложение работает плавно
- Память не растёт бесконечно (проверить в Xcode Instruments если доступно)
- Нет лагов при открытии/закрытии настроек

**Если провалено:** Retain cycles остались

---

### 🟡 MEDIUM #8: Translation languages limit

**Что тестируем:** Нет краша/глюков в списке языков перевода

**Как проверить:**
1. Открыть Telewhite Mods → Translation → Target Language
2. Проверить что список языков отображается корректно
3. Выбрать несколько языков подряд
4. Вернуться и снова открыть

**Ожидаемый результат:** Всё работает, нет визуальных глюков, строки в правильном порядке

**Если провалено:** stableId collision произошёл
