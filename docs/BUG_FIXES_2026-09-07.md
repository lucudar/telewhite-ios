## 🔴 CRITICAL #1: Division by zero в Registration Date

**Файл:** `submodules/TelegramUI/Components/PeerInfo/PeerInfoScreen/Sources/PeerInfoProfileItems.swift:271-275`

**Проблема:**
Когда userId точно совпадает с элементом датасета (51, 777000, 1000000, 2000000, и т.д.), происходит деление на ноль:
```swift
// До исправления:
let ratio = Double(userId - lower.id) / Double(upper.id - lower.id)
// userId=1000000, lower.id=1000000, upper.id=1000000
// ratio = 0/0 = NaN
// estimatedTimestamp = NaN
// Date(timeIntervalSince1970: NaN) → 2001-01-01 (некорректная дата)
```

**Решение:**
Добавлена проверка на точное совпадение перед интерполяцией:
```swift
if let lower = lowerBound, let upper = upperBound {
    // Проверка на точное совпадение (защита от деления на ноль)
    if lower.id == upper.id {
        // Точное попадание в элемент датасета
        registrationDate = Date(timeIntervalSince1970: lower.timestamp)
    } else {
        // Линейная интерполяция между двумя точками
        let ratio = Double(userId - lower.id) / Double(upper.id - lower.id)
        let estimatedTimestamp = lower.timestamp + ratio * (upper.timestamp - lower.timestamp)
        registrationDate = Date(timeIntervalSince1970: estimatedTimestamp)
    }
}
```

**Impact:** Критический — крашило для пользователей с "красивыми" ID (ровные миллионы)

## 🔴 HIGH #2: Race condition в Ghost Mode — онлайн может мелькнуть

**Файл:** `submodules/TelegramCore/Sources/State/ManagedAccountPresence.swift:45-63`

**Проблема:**
`ghostEnabled` читается один раз в начале функции `updatePresence()` и не перечитывается перед отправкой network request. Если пользователь включит Ghost Mode ПОСЛЕ чтения флага, но ДО отправки `updateStatus(offline: false)`, онлайн-статус уйдёт на сервер.

**Окно race condition:** До 30 секунд (таймаут повторного вызова)

**Сценарий:**
1. Пользователь открывает чат, Ghost Mode OFF → `wasOnline = true`
2. Начинает писать сообщение
3. Перед отправкой включает Ghost Mode
4. `updatePresence(true)` уже запущен с `ghostEnabled = false`
5. Отправляется `offline: false` — **онлайн виден на сервере**
6. Только потом `TelewhitePresenceGuard.assertOffline()` отправит offline

**Решение:**
Перечитывать `shouldSuppressPresence()` непосредственно перед каждым network request:
```swift
private func updatePresence(_ isOnline: Bool) {
    // Перечитываем ghost state перед каждым network request для предотвращения race condition
    // (пользователь может включить Ghost Mode между вызовами updatePresence)
    let ghostEnabled = TelewhitePresenceGuard.shouldSuppressPresence()
    let isOnline = isOnline && !ghostEnabled
    let request: Signal<Api.Bool, MTRpcError>
    if isOnline {
        // ...
        request = self.network.request(Api.functions.account.updateStatus(offline: .boolFalse))
    } else {
        self.onlineTimer?.invalidate()
        self.onlineTimer = nil
        // Перечитываем ghost state снова для else ветки
        let ghostEnabledNow = TelewhitePresenceGuard.shouldSuppressPresence()
        if ghostEnabledNow && self.wasOnline {
            // ...
        }
        request = self.network.request(Api.functions.account.updateStatus(offline: .boolTrue))
    }
}
```

**Impact:** HIGH — это ответ на открытый вопрос владельца: **ДА, онлайн может мелькнуть при включении Ghost Mode во время активности**

## 🟡 MEDIUM #3: Stories игнорируют per-chat ghost

**Файл:** `submodules/TelegramCore/Sources/TelegramEngine/Messages/Stories.swift:2074-2076`

**Проблема:**
`markStoryAsSeen` проверяет только `ghostMode` и `ghostStories`, но НЕ проверяет `ghostPeerIds` (per-chat ghost для конкретного пользователя). Все остальные функции (typing, read receipts) проверяют per-chat ghost, а stories — нет.

**Impact:** Если включить per-chat ghost для пользователя, его stories всё равно будут отмечены как просмотренные

**Решение:**
Добавлена проверка `ghostPeerIds`:
```swift
func _internal_markStoryAsSeen(account: Account, peerId: PeerId, id: Int32, asPinned: Bool) -> Signal<Never, NoError> {
    let defaults = UserDefaults.standard
    if defaults.bool(forKey: "telewhite.mods.ghostMode") || defaults.bool(forKey: "telewhite.mods.ghostStories") {
        return .complete()
    }
    // Проверка per-chat ghost для конкретного пользователя
    let ghostPeerIds = Set((defaults.array(forKey: "telewhite.mods.ghostPeerIds") as? [NSNumber] ?? []).map { $0.int64Value })
    if ghostPeerIds.contains(peerId.toInt64()) {
        return .complete()
    }
    // ... остальной код
}
```

## 🟡 MEDIUM #5: Nested closure в cache settings захватывает context

**Файл:** `submodules/SettingsUI/Sources/TelewhiteModsController.swift:1689-1693`

**Проблема:**
Вложенный closure в `updateSettings` снова strongly захватывает `context`:
```swift
let _ = (context.sharedContext.accountManager.sharedData(...)
|> take(1)).start(next: { sharedData in
    // strongly captures context
    context.account.postbox.mediaBox.setMaxStoreTimes(...)
})
```

**Решение:**
```swift
let _ = (context.sharedContext.accountManager.sharedData(keys: [SharedDataKeys.cacheStorageSettings])
|> take(1)).start(next: { [weak context] sharedData in
    guard let context = context else { return }
    let cacheSettings = sharedData.entries[SharedDataKeys.cacheStorageSettings]?.get(CacheStorageSettings.self) ?? CacheStorageSettings.defaultSettings
    context.account.postbox.mediaBox.setMaxStoreTimes(general: cacheSettings.defaultCacheStorageTimeout, shortLived: 60 * 60, gigabytesLimit: cacheLimit)
})
```

## 🟡 MEDIUM #7: stableId collision риск в translation languages

**Файл:** `submodules/SettingsUI/Sources/TelewhiteModsController.swift:1490-1492`

**Проблема:**
stableId вычисляется как `61 + index` (строка 674), следующий блок Privacy начинается с 100. Если `popularTranslationLanguages` содержит >= 39 элементов, произойдёт столкновение:
- 61 + 38 = 99 (OK)
- 61 + 39 = 100 (СТОЛКНОВЕНИЕ с `.privacyHeader`)

Это нарушит assert в `ItemListControllerNode.swift:449` и сломает diff алгоритм ItemListUI → визуальные глюки, неправильный порядок строк.

**Решение:**
Добавлено ограничение на максимум 38 языков:
```swift
// Защита от stableId collision: максимум 38 языков (61+38=99, следующий блок начинается с 100)
let maxLanguages = min(popularTranslationLanguages.count, 38)
for index in 0..<maxLanguages {
    let code = popularTranslationLanguages[index]
    entries.append(.translationLanguageOption(Int32(index), telewhiteLanguageDisplayName(code), code, normalizeTranslationLanguage(code) == current))
}
```
