# Telewhite iOS — передача контекста локальной сессии

Работа сделана в облачной сессии Claude Code, которая **не смогла запушить** ветку
(git-прокси сессии имеет доступ только на чтение: `Permission to
lucudar/telewhite-ios.git denied to lucudar`, HTTP 403 на `git-receive-pack`).
Девять коммитов переданы файлом `telewhite-9-commits.bundle`.

**Ничего из перечисленного ниже не проверено компилятором** — в облачном контейнере
нет ни Swift, ни Bazel, ни Xcode. Это главный риск: правок много и они переплетены.

---

## 1. Первое, что нужно сделать

```bash
# ветка из бандла
git fetch /path/to/telewhite-9-commits.bundle \
  claude/project-overview-89431t:claude/project-overview-89431t
git push -u origin claude/project-overview-89431t
```

Затем **не мержить в `master`**, а сначала прогнать сборку на ветке:
GitHub → Actions → **iOS IPA** → *Run workflow* → выбрать
`claude/project-overview-89431t`.

Локально (если есть macOS + Xcode 26.2) первый прогон стоит делать так — тогда все
ошибки вылезут за один проход, а не по одной:

```sh
source ~/.zshrc 2>/dev/null; python3 build-system/Make/Make.py --overrideXcodeVersion \
 --cacheDir ~/telegram-bazel-cache \
 build --continueOnError \
 --configurationPath build-system/appstore-configuration.json \
 --gitCodesigningRepository git@gitlab.com:peter-iakovlev/fastlanematch.git \
 --gitCodesigningType development --gitCodesigningUseCurrent \
 --buildNumber=1 --configuration=debug_sim_arm64
```

### Ключевые архитектурные решения

**Бейдж «Удалено»** (`ChatMessageItemCommon/Sources/TelewhiteDeletedBadge.swift`)
— плоское изображение на `ASImageNode`-оверлее, поэтому **не участвует в измеряемой
вёрстке** и не может испортить размер, который content-node только что сообщил.
Живёт в `mainContextSourceNode.contentNode` (пузырь) и на самом item-node
(видеокружок) — вне затемняемых обёрток, чтобы сам бейдж не тускнел. Позиция —
свободное поле сбоку от пузыря, с откатом в ведущий угол, если поле узкое.
Затемнение ослаблено 0.3 → 0.6, потому что сигнал теперь несёт бейдж.

**Переводчик.** Проверка перевёрнута: не «целевой язык — лучшая догадка?», а
«уверенно ли текст НЕ на целевом языке?». Русский регулярно распознаётся как
украинский/болгарский/сербский с высокой уверенностью — отсюда и перевод русского на
русский. Пороги: целевой язык среди 6 гипотез с p ≥ 0.15 → пропустить; ни одной
гипотезы ≥ 0.45 → пропустить; текст < 3 символов → пропустить. Вес одного сообщения
при определении языка чата ограничен 100 символами; автоперевод требует, чтобы
язык-победитель держал ≥ половины веса минимум по двум сообщениям.

**Профиль.** Две причины «скрывает, хотя выключено»: (а) `PeerTitle.swift` вырезал
подстановку номера вместо имени безымянным контактам **независимо от тумблера** —
восстановлено штатное поведение, теперь за настройкой; (б) шапка проверяла только
`isSettings`, поэтому «Мой профиль» проваливался к заглушке `—`, которая в
развёрнутой шапке рисуется белым поверх аватарки. Тумблер больше не прячет номер в
чужих профилях.

## 3. Как это проверялось без компилятора

Скриптами по AST-подобным инвариантам: все 63 пункта `TelewhiteModsEntry` покрыты в
`section`/`stableId`/`item`; нет ссылок на удалённые кейсы; нет дублей `stableId`;
12 вкладок имеют заголовок и ветку сборки записей; 43 поля настроек совпадают по
порядку с memberwise-init; все ключи и объявлены, и сохраняются; балансы скобок нулевые.

Это ловит несоответствия switch/enum, но **не** ловит: несовпадение типов в вызовах
API, отсутствующие импорты/зависимости BUILD, ошибки доступности iOS-версий.
Наиболее вероятные места падения:

1. `TelewhiteDeletedBadge.swift` — новый файл в `ChatMessageItemCommon`
   (у модуля `-warnings-as-errors`).
2. `LocalizedPeerData` получил зависимость `PhoneNumberFormat` — проверить, что
   цикла нет (по анализу его не должно быть: `AccountContext` не зависит от
   `LocalizedPeerData`).
3. SF Symbols в `telewhiteMenuIcon` — минимальная версия проекта iOS 13.0,
   выбраны глифы iOS 13 с запасным именем у каждого.
4. Новые кейсы вкладок (`.translator`, `.accentColor`, `.bubbleColor`,
   `.background`, `.shape`) — исчерпаемость switch по `TelewhiteModsTab`.

## 4. Открытые хвосты

- **Кружок при отправке видео.** Функция удалена целиком, потому что глобальный
  тумблер — неверная форма. Если нужно, вернуть как пункт **при отправке**
  (в media picker), а не как настройку.
- **Низкоуровневый API записи звука** (`OngoingCallContext.startCallRecording` →
  `OngoingCallThreadLocalContext.mm` → `TelewhiteStartRecording` в ADM) теперь
  никем не вызывается. Это правка внутри вендоренного tgcalls — вынесена отдельно,
  чтобы не задеть testbench.
- **`import AlertUI`** в `TelewhiteModsController.swift` выглядит неиспользуемым, но
  он был таким и до этих правок — оставлен, чтобы не рисковать без компилятора.
- **Превью в списке чатов** для удалённого последнего сообщения не помечается. Префикс
  сдвинул бы все диапазоны message entities (кастомные эмодзи, ссылки) в
  `chatListItemStrings` — сознательно не делалось.

## 5. Про подписи коммитов

Локальный stop-hook помечает коммиты как Unverified. Это ложное срабатывание:
`gpgsig` есть на всех девяти, автор и коммиттер — `noreply@anthropic.com`, а `N` в
`%G?` означает лишь невозможность локальной проверки без
`gpg.ssh.allowedSignersFile`. **Не** запускать `--amend --reset-author`: сменятся
хеши всех девяти коммитов и разойдутся с бандлом.
